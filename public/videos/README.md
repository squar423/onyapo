Place video files as EX0001.mp4, EX0002.webm, etc. Then register each video in src/data/videos.json or run `python3 scripts/add_video.py EX0001 --file ./clip.mp4`. Names must match the exercise ID. If a video isn't registered yet, the site shows a labeled demonstration placeholder instead of a broken video.

Only upload videos you own or have permission to share. If hosting many videos, use a video/CDN service and update the video handling accordingly; GitHub Pages is not intended as a large streaming CDN.
